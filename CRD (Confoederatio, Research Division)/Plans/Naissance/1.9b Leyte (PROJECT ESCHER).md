**Project Escher** (May-June/July 2026) takes place before SVEA II in order to lay the technical groundwork for more complex changes over time.
# Features:
- Add Geometry Relations
- Better auto-labelling:
	- Area threshold for sub-polygon
	- Remove colliding labels (toggle)
- Better mapmodes:
	- Default mapmodes: Geometry Relations, Geometry Tags, Has Variable, Variable Count/Variable
	- Default mapmode colourscales for geometries (vertical list format)
	- Mapmodes (Node Editor integration)
- Image references from projections:
	- Equirectangular (raster to vector for GeoJSON/KNN-binning)
	- Equirectangular overlay
- Merge Polygons operation
- Refactor Naissance to support all outstanding operations not yet implemented
- Rework selection to be able to select all geometries nested within a Feature/Select All
- Geometry operations:
	- Difference geometries
	- Intersect with geometries
	- Union with geometries
	- Transfer from selected geometries/all geometries
- Geometry keyframe editor
	- Geometries should have contour lines that reflect their date with heat scales, based on the shatter algorithm.
	- Masking the diff of keyframes within a date range can attribute it to a new geometry, at which point it is transferred to a polity within a date range. 
	  
	  Borderpool diffs may be done via shattering/filling borderpool polygons with a dynamic preview. Losses would be shown in red, gains in green. The selected fill should be marked in a white selection outline. Polygon masks may be manually edited with other brush tools before final operation (i.e. partitioning provinces).
- Shared Multiple Geometry Actions (between Selection/Features with multiple geometries)
