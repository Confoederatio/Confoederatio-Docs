**Project Escher** (May-June/July 2026) takes place before SVEA II in order to lay the technical groundwork for more complex changes over time.

**Note.** The codebase eis still lightweight and agile enough that any major changes should be implemented at this stage prior to horizontal expansion.

# DESIGN PILLARS.

1. The Timeline is **king**. All editing should be inspired off of video editors (cut, merge, etc). by having individual Layers with time domains and extent masks.
	1. Layers can be recursively loaded (other `.naissance` files), or within the same file.
	2. Brush actions and geometry actions should be unified.
2. Geometries should not be frontloaded. They should be placed in a multi-stream database such that they can be queried and operated on, with the main thread only serving to render and orchestrate operations.
3. DALS should be fixed so that it can work as full-stack version control, and Actions should be centralised and flattened to be less verbose.
# Features:
- Add Geometry Relations
- Better auto-labelling:
	- Area threshold for sub-polygon
	- Remove colliding labels (toggle)
- Better mapmodes:
	- Default mapmodes: Geometry Relations, Geometry Tags, Has Variable, Variable Count/Variable
	- Default mapmode colourscales for geometries (vertical list format)
	- Mapmodes (Node Editor integration)
- Branch inheritance for keyframes, i.e. for successor states. Multiple geometries can inherit the same geometry's keyframes, these point back to the original geometry
- Clip Timeline:
	- Creates a new 'Time Layer' within a specified time domain, where new polygons can be created and merged back into the main timeline via split screen attribution, i.e. for conflict mapping. Clones keyframes of selected polygons at that date.
- Image references from projections:
	- Equirectangular (raster to vector for GeoJSON/KNN-binning)
	- Equirectangular overlay
	- Multi-image overlay (Layer type)
- Merge Polygons operation
	- Merge Keyframes Into (within selected keyframe range)
	- Merge Polygons (with Keep Symbol/Overwrite Data toggles)
- Mod support (similar to plugins)
	- Mods contained in `saves/mods` with an associated `.naissancemod` extension (JSON5) and folder. The `.naissancemod` file contains information on execution order and metadata.
	- Mods can be manually run after startup, or upon startup as well.
	- `settings.json` should contain an enabled/disabled mods list.
- Move DALS actions for geometries to `MultiGeometry_actions`
- Refactor Naissance to support all outstanding operations not yet implemented
- Rework selection to be able to select all geometries nested within a Feature/Select All
- Geometry operations:
	- Delete duplicate geometries
		- Area filtering (via threshold of ~10km^2)
	- Difference geometries
	- Intersect with geometries
	- Union with geometries
	- Transfer from selected geometries/all geometries
	- Truncate floats on Lnglats (compression); round to n decimal places
- Geometry keyframe editor
	- Geometries should have contour lines that reflect their date with heat scales, based on the shatter algorithm.
	- Keyframes can be selected/deselected from the currently rendered borderpool/diff
	- Masking the diff of keyframes within a date range can attribute it to a new geometry, at which point it is transferred to a polity within a date range. 
	  
	  Borderpool diffs may be done via shattering/filling borderpool polygons with a dynamic preview. Losses would be shown in red, gains in green. The selected fill should be marked in a white selection outline. Polygon masks may be manually edited with other brush tools before final operation (i.e. partitioning provinces).
- Selection groups/global operations
	- Global Operation (Brush Mode)
		- Shift + Click with the selected topbar group leads to a Geometry being assigned to that named selection group, alternatively an entire Group/Layer
		- Selected topbar groups can be named, sorted, searched, and colour-coded
	- Default groups: Groups, Layers, All Geometries, (Geometry Types), Tags
	- Operations are modular, meaning they are stringed in an ordered list (1, 2, 3, 4, etc).
	- Operations will use the selected date range for targeting
	- Add To
	- Buffer/Simplify (simplify includes both tolerance/truncate)
	- Clip To Mask
	- Merge With Polygon
	- Subtract From
- Shared Multiple Geometry Actions (between Selection/Features with multiple geometries)
